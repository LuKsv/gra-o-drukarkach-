# ROADMAP — Farma Drukarek 3D

## ETAP 1: Prototyp Grywalny (MVP)
- [x] Struktura projektu (HTML5, JS, CSS)
- [x] Zapis lokalny postępu
- [x] Pierwsza drukarka (budżetowa)
- [x] 3-4 przykładowe zlecenia (breloczki, figurki, części)
- [x] Picker ustawień: materiał, temperatura, wysokość warstwy, wypełnienie, podpory
- [x] Symulacja druku (skrócony czas)
- [x] Wynik druku (idealny/dobry/z wadami/porażka) na podstawie ustawień
- [x] System ocen klientów (gwiazdki 1-5)
- [x] Zarabianie i zakup kolejnych zleceń
- [x] Interfejs mobilny (portrait, touch-friendly)
- [x] Encyklopedia: krótkie opisy materiałów i ustawień

## ETAP 2: Rozbudowa Mechanik (2-3 sesje)
- [ ] Druga drukarka (lepsze możliwości)
- [ ] Ulepszenia: hotend, stół, suszarka filamentu
- [ ] Magazyn filamentów (złe przechowywanie → zwilgotnienie)
- [ ] Więcej typów zleceń (cosplay, prototypy, części zamienne)
- [ ] Stali klienci z preferencjami
- [ ] System reputacji (wpływ na dostęp do zleceń)
- [ ] Bardziej szczegółowe błędy druku z poradami

## ETAP 3: Automacja i Grind (3-4 sesje)
- [ ] Pracownicy (wolni pracownicy automatyzują druk)
- [ ] Codziowe zadania (daily challenges)
- [ ] Osiągnięcia
- [ ] Poziomy firmy (100 PLN → warsztat zarabiający sam)
- [ ] Rozbudowa warsztatu (nowe stanowiska)

## ETAP 4: Finał i Wydanie (1-2 sesje)
- [ ] Balans ekonomiczny (nie za łatwo, nie za trudno)
- [ ] Reklamy (szablony AdMob w kodzie)
- [ ] Jednokrotny zakup "bez reklam"
- [ ] Testowanie na slowszych telefonach
- [ ] Pakowanie Capacitor + publikacja na Play Store
- [ ] Przygotowanie strony/nagrania promocyjnego

## NOTATKI
- Priorytet: grywalność i balans > nowe mechaniki > wygląd
- Każde wydanie musi być grywalne całkowicie
- Zapisany postęp nigdy nie może zostać zniszczony
- Rzeczywista wiedza 3D print > dowolne wymyślone wartości
